# BetterWidgets 1.0

BetterWidgets puts images, GIFs, and looping videos on the macOS desktop.

- Compact cards in the widget manager and media library, with clear controls and file names without extensions.
- Add individual media files, browse folders, or drop a file onto Add Widget.
- Move and resize widgets in Edit Widgets mode while preserving media proportions.
- Show and hide widgets, replace media, and mute videos.
- Restore saved widgets, desktop positions, sizes, and enabled states after restarting.
- Recognize unavailable files, follow moved files through bookmarks, and replace missing media without losing the saved widget.
- Show the manager on the first manual launch; support background launch at login and reopening from the menu bar.
- An About window with version, author, and a short guide.
- Keep the application menu and Dock icon while the manager or About window is open, including across Spaces; return to background mode when both close.
- Release GIF frames, timers, video players, and hosted media when widgets close; report corrupt video playback and clear stale GIF frames after replacement.
- Bound thumbnail memory and concurrent generation, share duplicate requests, and refresh previews when files change.
- Scan media folders and image metadata in the background, exclude directories, and balance file access after repeated folder moves.
- Protect saved data with duplicate widget or folder identities; route the system About command to the app's About window and remove the empty Settings command.

Requires macOS 14 or later. Release packages include Apple silicon and Intel binaries.
